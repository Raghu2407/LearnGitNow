# InteractiveGit

A beginner-friendly Git command reference you can actually use — search any command, read what it does in your language, and copy it straight to your terminal.

---

## How to Use

### 1. Open the Website
Just open the `git-commands-reference.html` file in any browser. No installation, no setup.

### 2. Switch Your Language
At the top-right corner there is a **language dropdown**. Pick your preferred language:
- 🌐 English
- 🇮🇳 ಕನ್ನಡ (Kannada)
- 🇮🇳 हिंदी (Hindi)

Every description, example note, and label on the page switches instantly.

### 3. Toggle Dark / Light Mode
Click the **☀️ / 🌙 button** next to the language dropdown to switch between light and dark mode based on your preference.

### 4. Search for a Command
Use the **search bar** in the header. Type any command name like `stash`, `push`, `rebase`, or even a keyword like `undo` or `branch` — the page filters results live as you type.

### 5. Browse by Category
Use the **left sidebar** to jump directly to a category like Branching, Stash, Remote, etc. The sidebar highlights the section you are currently reading as you scroll.

### 6. Read and Understand a Command
Each command card shows:
- The **command name**
- A plain-language **description** in your chosen language
- The **syntax** showing how to write the command
- **Examples** with a short note explaining what each one does

### 7. Copy a Command
Every example has a **Copy button** on the right side. Click it and the command is copied to your clipboard — ready to paste into your terminal.

---

## Quick Example — Using Stash

> You are working on a feature but need to quickly switch to another branch to fix a bug. You don't want to commit your half-done work.

1. Search **"stash"** in the search bar
2. Read the description in your language to understand what stash does
3. Copy `git stash` and run it — your changes are saved temporarily
4. Switch branches, fix the bug, come back
5. Copy `git stash pop` to restore your work exactly where you left off

That's it — InteractiveGit is built for moments exactly like this.
